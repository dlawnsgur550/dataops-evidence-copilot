# 실제 LLM의 비용과 키 보안

이 문서는 CHECKPOINT 3의 정책·검증 이력을 보존한다. 최신 Flex 단가·평가 요청 수·컨테이너 격리·현재 비용은 `KEY_COST_CURRENT.md`를 기준으로 한다.

2026-10-20 기준. 공유 API 키는 사용자가 입력한 명시적인 `work/runtime/openai.env`에서만 읽는다. 키 값·일부 문자열·지문을 출력하지 않는다. 기본 CLI와 pytest는 fake여서 API 요금이 없다.

## 모델과 요금

기본 유료 모델은 `gpt-6-luna`다. 이 제한된 구조화 진단의 저비용 선택이며 모든 모델 중 품질 대비 가치가 최고라는 비교 평가는 하지 않았다. 모델을 자동으로 올리거나 다른 모델로 바꾸지 않는다. Responses API, reasoning `none`, service tier `default`, `store=false`, `tools=[]`를 사용한다. 유료 검색·파일 도구는 없다.

| --- | ---: | ---: | ---: | ---: |
| 적용 단가 | 0.10 | 0.01 | 0.125 | 0.50 |

공식 근거: [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [요금표](https://developers.openai.com/api/docs/pricing), [Responses API](https://developers.openai.com/api/reference/python/resources/responses/methods/create), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs). 기준일 이후 단가가 바뀌면 코드의 단가와 보수적 예약식을 함께 검토한다. 보고서의 비용은 API 응답 토큰 수에 이 단가를 적용한 추정치이며 계정 청구서를 조회한 금액이 아니다.

## 비용 차단

| 범위 | 로컬 차단 기준 |
| --- | --- |
| 이 장부의 누적 | $0.05, 유료 요청 최대 50회 |
| 하루 | $0.02, 최대 20회, Asia/Seoul 날짜 |
| 진단 1건 | $0.01, 유료 요청 최대 4회 |
| 요청 1건 | 사전 추정 $0.005 이하, 본문 24,000 UTF-8 바이트 이하 |
| 출력 | Triage 256, Inspector 160, RCA 1,200, Reviewer 512 토큰 |

SQLite의 `BEGIN IMMEDIATE`로 동시 프로세스도 네트워크 전 예산을 예약한다. 본문 UTF-8 바이트 수에 2,048의 여유를 더해 캐시 쓰기 단가와 최대 출력을 반영한다. 정상 응답은 사용량으로 정산하고, 시간 초과·HTTP 오류·사용량 누락은 예약액을 유지한다. 예약액을 넘는 사용량이 관측되면 이후 호출을 차단한다. 예약액 유지가 실제 과금을 확정하는 것은 아니다.

**이는 이 앱·이 로컬 장부의 방어 기준이다. OpenAI 계정 전체의 강제 결제 한도가 아니며 다른 사람이 공용 키로 쓴 비용을 보거나 통제하지 못한다.** 제공자 단가 변경·미확인 청구까지 포함한 절대 과금 상한을 보증하지 않는다. 계정·조직의 공용 설정을 변경하지 않았다. 장부를 삭제하거나 다른 경로를 지정해 상한을 초기화하지 않는다.

인증 오류·429·서버 오류·잘린 출력·의미 검토 거절을 자동 재호출하지 않는다. 유료 모드는 그래프 호출 예산도 4회라 자동 RCA 재작성 분기를 타지 않는다. 수동 재실행도 같은 누적·일일 장부를 사용한다. 성공한 각 역할의 응답은 요청 해시로 로컬에 24시간 캐시한다. 요청 본문·스키마·프롬프트가 같을 때 캐시를 재사용하며, 변경되거나 만료되면 비용이 발생할 수 있다. 잘못된 캐시는 무료로 중단하며 자동 유료 복구를 하지 않는다.

## 키와 데이터

- 런타임·캐시 디렉터리는 700, 키 설정·SQLite 장부·캐시 파일은 600이다. 사용자 소유 프로세스와 관리자는 접근할 수 있다. 키 암호화 저장이나 Keychain 연동은 구현하지 않았다.
- 키는 `SecretStr`로 보관하고 HTTPS Authorization 헤더로만 보낸다. 명령 인자·모델 본문·보고서·캐시·비용 장부에는 넣지 않는다. 고정 OpenAI endpoint, 리다이렉트 금지, 환경 프록시 자동 사용 금지다.
- 명시적인 설정 파일의 키와 모델만 읽으며 자동 `.env` 로딩이나 계정 인증 파일 탐색을 하지 않는다. 설정 파일과 장부의 심볼릭 링크를 거부한다.
- 모델에는 허용 필드만 보내고 로그 일부·샘플 3개·런북 3개를 제한해 전달한다. 자격 문자열·실제 키·키 패턴·로컬 사용자 경로를 제거한다. 진단에 필요한 식별자와 제한된 증거 내용은 OpenAI로 전송된다.
- `store=false`로 응답 저장을 끈다. 이것만으로 모든 제공자 로그 보존이 0이 된다는 뜻은 아니다. 외부 LangSmith 추적은 끈다.
- 모델은 진단 JSON만 반환하며 실제 MCP는 조회 도구 5개만 노출한다. 복구 단계는 사람이 검토할 설명이고 자동 SQL·셸·복구 실행을 하지 않는다.

## 실행

프로젝트 루트에서 저장된 실제 증거를 재생하려면 다음과 같이 실행한다. 아래 명령은 캐시가 없거나 입력이 바뀌면 유료다. 키 값을 명령에 붙이지 않는다.

```bash
uv run dataops-copilot \
  --replay-report artifacts/checkpoint2/schema-report.json \
  --llm openai \
  --api-settings /Users/lim/Documents/Codex/2026-10-20/dataops-candidate-c/work/runtime/openai.env \
  --output artifacts/checkpoint3/my-openai-report.json
```

실시간 경로는 README의 `--settings … --incident …`에 같은 `--llm openai --api-settings …`를 추가할 수 있다. 이번 체크포인트에서는 비용을 줄이기 위해 저장된 실제 스키마 증거만 사용했다. 현재 Airflow·DB·MCP를 새로 조회한 실행으로 세지 않는다. 자동 테스트와 감사 스크립트는 API 호출이 없다.

## 검증

실제 요청 7회에 대해 토큰을 수집했고 단가 기반 누적 추정 비용은 **$0.00264445**다. 불확실 예약은 0건이다. 최초 Reviewer 출력 상한 실패와 근거/런북 ID 혼용 거절을 보존하고, 필요한 역할만 수동으로 재실행했다. ID를 별도 enum으로 제한한 후 스키마 장애 진단·코드 검토·의미 검토가 통과했다. 동일 입력 재실행은 API 0회·캐시 4회·추가 비용 $0였다.

71개 pytest는 실키를 사용하지 않는다. 신규 17개는 권한·본문 비밀값 제거·무료 캐시·HTTP 오류 무재시도·사용량 누락·출력 잘림·입력 상한·동시 예산 예약·진단 상한·과다 사용 회로 차단·구조화 스키마·ID 분리·안전한 실패 보고를 검증한다. 별도 `scripts/audit_checkpoint3.py`는 사용자 지정 키의 출력물 노출, 파일 권한, 실제 사용량·캐시 보고서와 중지된 서비스를 검사하고 API를 호출하지 않는다.
