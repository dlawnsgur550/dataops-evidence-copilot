# 호스트 이름 해석 실패 / DNS

문서 ID: rb-dns
버전: 2
수정일: 2026-10-20
자료 유형: 직접 작성한 운영 절차

## 증상
could not translate host name, name resolution, NXDOMAIN, DNS, dbt_orders

## 확인과 원인 구분
실패 로그의 실제 호스트 이름과 이름 해석 오류를 확인하고 실행 환경의 resolver 설정을 대조한다.

## 사람의 조치
개발자가 호스트 이름과 네트워크·resolver 구성을 검토한다. 확인된 오타 또는 DNS 설정을 승인 후 정정한다.

## 선행 조건
실제 프로세스가 사용한 호스트와 DNS 오류 증거가 필요하다.

## 검증
이름 해석과 해당 대상 연결, 새 파이프라인 실행·품질 검사를 확인한다.

## 적용 제외
연결 거부만으로 DNS 장애를 확정하지 않는다. IP가 같다는 추측으로 다른 연결 성공을 차용하지 않는다.
