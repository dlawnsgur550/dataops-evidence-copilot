# 원천 필수 키 누락을 격리

문서 ID: case-key
버전: 1
수정일: 2026-10-20
자료 유형: 교육용 합성 장애 기록. 평가셋과 별도 작성.
관련 절차: rb-quality

## 관측
선택 실행 not_null 실패와 제한된 현재 프로필을 구분해 설명했다. 중복 0건은 NULL 부재를 뜻하지 않았다.

## 대응과 검증
원본을 보존하고 승인된 원천 정정 절차 후 새 실행의 not_null·unique와 건수·합계를 검증했다.

## 한계
특정 실행의 정답이 아니며 이 기록만으로 현재 원인을 확정하지 않는다. 원본·실행 식별자를 대조한다.
