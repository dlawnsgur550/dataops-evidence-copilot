# 계약 검토 후 컬럼 매핑 정정

문서 ID: case-contract
버전: 1
수정일: 2026-10-20
자료 유형: 교육용 합성 장애 기록. 평가셋과 별도 작성.
관련 절차: rb-schema

## 관측
선택 실행 로그가 누락 컬럼을 지목하고 같은 invocation 결과가 실패했다. 현재 계약 차이는 보조 자료였다.

## 대응과 검증
개발자가 업무 의미를 확인하고 매핑을 정정한 뒤 새 실행의 전체 태스크·두 품질 검사·집계를 확인했다.

## 한계
특정 실행의 정답이 아니며 이 기록만으로 현재 원인을 확정하지 않는다. 원본·실행 식별자를 대조한다.
