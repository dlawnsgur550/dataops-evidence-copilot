# 인증·권한 거부 / authentication permission denied

문서 ID: rb-auth
버전: 2
수정일: 2026-10-20
자료 유형: 직접 작성한 운영 절차

## 증상
password authentication failed, 28P01, 42501, permission denied, role, grant

## 확인과 원인 구분
실패한 실제 역할과 DB의 인증·권한 오류 코드를 확인한다. 연결 거부와 구분한다. 비밀번호 값을 수집하거나 출력하지 않는다.

## 사람의 조치
관리자가 최소 권한과 자격 유효성을 확인하고 승인된 경로로 접근 설정을 정정한다. 에이전트는 권한을 부여하지 않는다.

## 선행 조건
정확한 실행 계정과 대상, 승인된 자격 관리 담당자가 확인돼야 한다.

## 검증
같은 역할·같은 대상의 새 실행과 품질 검사 통과를 확인한다.

## 적용 제외
connection refused는 인증 전 연결 실패일 수 있으므로 비밀번호 오류로 단정하지 않는다.
