# 관측 연결 성공과 실행 연결 실패의 분리

문서 ID: case-endpoint
버전: 1
수정일: 2026-10-20
자료 유형: 교육용 합성 장애 기록. 평가셋과 별도 작성.
관련 절차: rb-connection

## 관측
관측 계정 접속은 성공했으나 dbt 실행 연결은 거부됐다. 실패 당시 포트는 로그에 없어 잘못된 포트라고 단정하지 않았다.

## 대응과 검증
실제 실행 설정을 확인한 개발자가 설정을 정정하고 새 실행의 태스크·품질·집계로 복구를 확인했다.

## 한계
특정 실행의 정답이 아니며 이 기록만으로 현재 원인을 확정하지 않는다. 원본·실행 식별자를 대조한다.
