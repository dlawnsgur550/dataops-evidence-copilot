# v2 사전 평가 규칙

v1 코드·프롬프트·12건 최종 결과와 ZIP을 변경하지 않는다. v2는 별도 디렉터리다. 이미 분석한 v1의 dev 6건과 final 12건은 무료 회귀검사용이며 새 최종 정확도로 집계하지 않는다.

수정 후 직접 작성한 H01 품질·H02 연결 합성 증거 2건만 유료 비교한다. 독립 외부 자료나 통계적으로 충분한 최종셋이 아닌 소규모 확인이다. v1의 8/9 목표를 재충족했다고 주장하지 않는다. 정상·보류·주입 로그와 스키마 오류는 무료 회귀검사로 검증하며 실제 LLM 일반화 성능을 증명하지 않는다.

각 방식에 다섯 관측 전체를 독립 제공한다. baseline은 다른 방식의 수집 실패 영향을 받지 않는다. 평가용 Inspector 지시에는 나머지 네 도구 전체 수집을 추가한다. 실제 제품의 선택적 수집 정책과 구분하며, RCA 직전 다섯 관측이 없으면 네트워크 호출을 차단한다. 수집 관측 수와 해시를 기록하고 일부만 수집하면 동일 입력 비교 성공으로 세지 않는다. baseline은 Luna 한 번과 고정 문서 ID 목록, v2는 같은 Luna·Flex·reasoning none·RCA 출력 1200 상한에 네 역할·검색·코드 및 의미 검토를 사용한다. 전체 시스템 비교이며 개별 기술의 효과를 분리하지 않는다. 정답은 두 방식의 결과가 저장된 뒤 채점에만 읽는다.

원인 유형·필수 근거·조치 대상·사람의 승인된 수정과 새 실행 검증을 확인한다. 명시적인 partial receipt와 missing_artifacts 없이 run_results가 누락됐다는 단정은 거절한다. 현재 성공 probe를 역사적 실패나 실제 복구 증명으로 쓰지 않는다. 앞으로 추가할 검사 제안과 현재 이미 실행된 검사에 관한 사실을 구분한다.

기존 공유 장부에 최대 10회만 추가한다. 하루 96·누적 128 evaluation 요청 제한과 기존 금액 상한 하루 $0.02·누적 $0.05·진단 $0.01·요청 추정 $0.005·진단 최대 4요청을 유지한다. 두 사례를 완주하는 데 필요한 최대 10회 외 추가 호출·출력 수리·고가 모델·일반 요금 fallback은 없다. 오류나 검토 거절이면 해당 결과를 보존하고 유료 배치를 멈춘다. 원문을 추측해 고치지 않는다. 재실행해도 저장 결과와 최초 장부 창을 재사용한다.

모델 호출 전 코드·테스트·프로토콜·증거·별도 정답을 v2-freeze.json으로 고정한다. 최초 결과를 본 뒤 고정 코드를 조정하지 않는다. Codex 근거 대조와 공란 사람 검토표를 구분한다. 독립 사람 검토는 사람이 작성하기 전까지 미완료로 둔다.
